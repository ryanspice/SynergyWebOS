Windows key target

Client side

When the pointer is on the TV, the Windows key can return to the TV's own system home. It is consumed, so no stray Meta key reaches the TV.

0 ms

0 ms sends HOME on the first press. A longer hold cancels if the key is released early. This is separate from the desktop handoff delay.
